`src/content/projects.ts`. Filenames map to slots there.

`derived/hero-texture.jpg` is a 1600px JPEG generated by
`scripts/derive-assets.mjs`. The W.01 shader uploads it as a GL texture via
`new Image()`, which bypasses next/image entirely — a 2.5MB PNG there would
wreck LCP. Regenerate it if the hero image changes.

## Note on the sizes

These are roughly 1000-1500px on the long edge. That is fine for cards and
gallery slots but thin for a full-bleed hero on a large display, where the
browser wants 2560px or more. If larger originals exist, they are worth
dropping in; the pipeline will use them automatically.
